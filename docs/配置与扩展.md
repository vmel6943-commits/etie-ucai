# 当前配置与扩展

## 剧情与交互

第一幕的下一步指引集中在 `game/presentation.ts` 与 `App.tsx` 的 guidedContinue，第一幕不设猜编号或机关门槛。场景热点仍可触发探索、收藏、环境与角色回应。

第二幕分两段。专报内容在 `data/reports.ts`（三份情报共用一套模板），五项任务的内容分别在 `data/opinion.ts`、`data/adVideos.ts`、`data/puzzle.ts`、`data/crisis.ts`、`data/tracking.ts`。

推进判定集中在 `game/flow.ts`，都是纯函数：`informantAction`（读专报 / 开箱 / 进工作台）、`platformAction`（检票 / 首次登车 / 回车厢）、`workbenchAction`（留在工作台 / 补记判断 / 最终判断 / 进第三幕）、`reportCloseTarget`（关闭专报是否接皮箱）、`endingMissing`（盖章还缺什么）。组件只负责把判定结果变成一次跳转或一个面板，测试可以直接驱动整条链。

五项任务的门槛只看各自的完成标记（`game/workbenchQuest.ts`）：`opinion-done`、`coke-material:film`、`puzzle-solved`、`crisis-done`、`tracking-done`。新增任务时只需在这里补一行，并让任务自己写这个 flag；**不要**在“打开面板”时写完成标记。

多步操作会存中间进度：拼图位置（`choices['puzzle-placements']`）、舆情进度（`choices['crisis-run']`）、神秘电波播到第几句（`choices['signal-progress']`）。新增多步任务时照这个办法存 `choices` 里的 JSON 字符串，读取时做一遍结构校验。

## 对白来源与返回

对白会话包含 scene 和 epoch。内部 go、画内返回与路由返回会让旧会话失效；渲染时与结束回调均检查归属。新对白读取当前 Store 中的 scene，不能使用跳转前闭包里旧的 scene。面板也绑定来源场景。

对白收尾统一走 `App.tsx` 的 `endDialogue(runAfter)`：正常读完与点“跳过这段对白”都会执行该对白的后继回调，画内返回与换场景则只清空界面（`closeDialogue`）。新增对白时，把“接下来要发生的事”放进 `after`，不要写在按钮里，否则跳过时衔接会断。

增加新的导航入口时，调用统一 go 或交给已有路由处理，避免只修改背景而保留旧对白。打开历史或设置时保持当前对白，暂停其自动播放。

## 场景配乐

`data/music.ts` 声明曲目与场景关系，`components/Music.tsx` 保留两路 audio 元素，`utils/audio.ts` 控制播放与切换。

首次播放必须由点击解锁；更换场景时使用双播放器交叉渐变；对话期间降低到正常音量的约46%；浏览器隐藏时暂停。静音与音量保存在用户设置中。背景音乐使用随包MP3，交互提示音使用 Web Audio。

增加音乐时将文件放入 public/music 并配置路径、标题与使用场景。原始原创配乐脚本在 scripts/compose-music.py；它只用于重新制作音轨，浏览器运行不需要 Python 或 ffmpeg。

## 美术与存档

运行资源唯一索引为 assets.json，原文件名、尺寸、透明通道与路径在美术资源清单.json。手机和电脑分别使用对应构图与热点。对白不再额外叠加全身人物，背景里的正式角色承担画面表演。

存档格式保持版本1，已有浏览器进度直接继续；本轮体验标记 story-v2 用于默认音频设置更新，显式静音记录优先保留。第二幕改成五项任务后，旧存档里的 `evidence` 虽会保留，但不再计入任务；工作台会在检测到旧调查记录时提示需要重做五项。

浏览器禁止本地存储时，存档写入会失败并在顶栏提示“请导出存档”。**不要**把“回读 localStorage 校验”当作任务完成的必要条件——内存里的状态才是本次旅程的依据，写入失败只应提示，不应阻断流程。

多设备与多人数据需真实后端，本版只记录个人体验。
