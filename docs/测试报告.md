## 浏览器全流程验收（无头 Edge，109 项断言全通过）

从封面开始，用真实点击走完全部三幕，逐段检查界面与剧情是否接上：

1. 封面 → 开启旅程 → 列车长对白 → 跳过对白后**自动**打开邀请函。
2. 抬信封 → 揭火漆 → 展信纸 → 出发 → 雾中车站。
3. 走进大厅 → 车站广播 → **乘务员自动承接** → 直接进入制票面板。
4. 领票 → 车票面板 → 前往检票口 → 递票盖章 → 走向站台 → 登车。
5. 登车对白 → **自动弹出旅途地图** → 收好地图 → 车厢 → 情报贩子。
6. 跳过对白 → **自动打开列车专报** → 追踪三层传播 → 初次判断 → 揭开真相 → 收好专报 → **自动接上皮箱**。
7. 开箱 → 进入工作台（0/5）。
8. 五项任务依次完成：广告档案（确认后计入）、个人观点（两页）、情报拼图室（四张归档）、舆情急救室（三次行动 + 报告）、查看最新信息（四份查阅）。
9. 任务栏显示“五项情报调查任务已全部完成” → 进入下一场景 → 最终判断 → 提交 → 收好材料。
10. 情报贩子收尾对白 → 乘务员在夜行车厢迎接 → 到达乘客车厢，车厢导航出现。
11. 手账台 → 盖章页显示“都已经在手账里” → 盖章 → 告别对白 → 跳过 → 结尾页“今夜，值得收藏。”。
12. 刷新页面：仍在结尾页，进度保留。
13. 从结尾页点“登车大厅”可以回到第一幕。

## 已知限制

- 上一版存档进入新版本时，第二幕需要重新完成五项任务（工作台有提示；第一幕车票与收藏、第三幕已验证的进度都保留）。
- 工作台桌面底图的插画里仍能看到“鹅印快车公司”“鹅印快车报社”旧字样，以及无法辨认的乘务记录姓名——这是底图上的绘画文字，需要重绘底图才能彻底替换。
- 手机端工作台底图在上一轮更换过构图，五个热点的相对位置只对上了“报纸/查看最新信息”和“电视/广告档案”两处，另外三处偏高或偏在照片墙上。桌面端五处都准确。该问题属于美术与坐标的配合，需要美术确认后统一调坐标或重画底图。
- 广告播放器继续依赖来源平台（YouTube / 腾讯视频），播放可用性取决于平台与网络；不可内嵌的影片只给原视频入口。
- 尚未在真实 iOS / Android 与微信内置浏览器上复验声音、系统分享与图片保存；模拟浏览器不能替代这一步。
