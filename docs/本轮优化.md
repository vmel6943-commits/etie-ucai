# 鹅铁U彩 UI 与交互优化交接

## 内容基准

以用户上传的车票与情报工作台最终交接版为基础。第二幕的新闻材料、题目、五项任务和新版车票继续沿用。

角色显示为乘务员、神秘情报贩子、列车长、手账记录员。组别署名为【值周七组】烧鹅濑粉组。

## 修改

1. 统一封面、顶栏、信件、角色档案、行李牌、票面、分享图、下载文件名和浏览器标题。旧存档中的脚本对白同步使用角色名，旅客昵称和自主输入继续保留。
2. 新增 `src/ui-refresh/experience.css`，统一文字层级、羊皮纸面板、深绿色对白及黄铜控件。手机输入框使用至少 16px 字号，操作按钮有明显焦点和触摸反馈。
3. 用统一底部布局和实际高度测量排列剧情引导、任务栏与车厢导航，为场景图预留空间。各热点继续按画面坐标定位。
4. 五项任务均提供底部入口，最新信息在紧凑按钮上使用「最新信息」。工作台热点与任务栏采用同一完成判断，旧版材料记录不会误显示为新任务已完成。
5. 修复窄屏热点文字挤成竖排、导航末项被裁切、对白角色名重复显示、弹窗切换后滚动位置残留。第三幕手机端默认显示发光热点，「看看四周」可以展开物件标签。
6. 查看历史记录时暂停对白逐字显示和键盘推进。弹窗打开时停用背景交互，支持 Escape、键盘焦点循环和关闭后的焦点恢复。
7. 完成全部五项后的提示使用独立浮层，避开底部容器变换造成的裁切。首次进入第三幕前补齐最终判断，保证车厢导航与收尾记录可用。
8. 情报拼图支持点击归档与标准拖放数据传递。完成提示聚焦继续按钮。
9. 场景图片加载失败时提供重试，预加载下一场景对应的手机或桌面素材。
10. 图片模型修改桌面工作台铭牌、报纸标题和乘务记录文字，以及手机工作台的品牌字样。保留原有皮箱构图与热点布局。

## 验证

- 15 项自动测试通过，TypeScript 检查和 Vite 生产构建通过。
- 浏览器走查桌面、390px 和 320px 手机视口，检查封面、工作台、对白记录、车票及纪念图、第三幕导航。
- 实际完成两道观点投票、四张线索归档、四份资料查阅、三次舆情操作，并打开广告档案，核验 5/5 提示、进入下一场景和刷新后的任务完成记录。
- 广告播放器继续依赖来源平台。此轮验证覆盖播放器入口和切换，播放可用性取决于平台与网络。

## 主要文件

- `src/ui-refresh/experience.css` 为本轮全局体验样式，在 `main.tsx` 最后导入。
- `src/App.tsx` 负责自适应底部布局、场景重试和剧情衔接。
- `src/game/legacyHistory.ts` 处理旧对白名称迁移。
- `src/scenes/CokeMaterials.tsx` 负责五项任务入口、状态与完成提示。
- `public/assets/workbench.webp` 与 `workbenchMobile.webp` 为已接入的新版底图。

## 图片修改提示词

使用内置图片模型编辑原有底图。桌面提示要求保持 16∶9 构图、物件位置、光影、皮箱分区与热点区域，修改铭牌为「鹅铁U彩 / ETIE UCAI」、报纸标题为「鹅铁U彩：未完待续！」，将乘务记录中的人物姓名改为角色。手机提示要求保持 9∶16 构图和全部物件位置，将背景旗帜和报纸的品牌文字修改为「ETIE UCAI」。生成模型对细部纹理和小字有轻微重绘，运行图按原纵横比接入。
