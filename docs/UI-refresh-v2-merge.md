# 鹅铁U彩 · 视觉精修层 v2 合并说明

本批改动由 UI 线独立完成，目标是**在不触碰 3D / 2.5D 效果的前提下**提升整体视觉与票面质感。
所有改动集中在一个新增样式文件里，组件代码**零改动**，便于与另一位同学的版本直接合并。

## 一、改动清单

| 文件 | 状态 | 说明 |
| --- | --- | --- |
| `src/ui-refresh/sunday-refresh.css` | **新增** | 全部视觉精修的唯一样式文件（约 690 行，含注释） |
| `src/main.tsx` | **改 1 行** | 在原有 CSS 之后新增一行 import |

除此之外**没有任何文件被修改**，`src/` 下的组件、场景、数据、存档、测试均与原交接包逐字节一致。

`src/main.tsx` 的唯一改动：

```diff
 import './ui-refresh/vintage-ui.css';
+import './ui-refresh/sunday-refresh.css';
```

## 二、合并步骤

1. 先备份对方版本（`git commit` 或整目录复制）。
2. 把 `src/ui-refresh/sunday-refresh.css` 复制到对方项目的同一路径。
3. 在对方的 `src/main.tsx` 里，找到 `import './ui-refresh/vintage-ui.css';` 这一行，
   **在它下面**加一行 `import './ui-refresh/sunday-refresh.css';`。
   - 如果对方也新增了 CSS，把本行放在**这些新增 CSS 的最后**。
   - 如果对方在 `main.tsx` 里加了 3D 初始化代码，**保留原样**，只插入这一行 import。
4. 执行 `npm ci && npm test && npm run build`，然后按第三节走查。

整个合并只有「复制 1 个文件 + 插入 1 行」，不需要 `git apply` 补丁，也不存在逐处手工比对的风险。

## 三、验收走查

- 开场封面：标题应使用厚重宋体（华文中宋 / Songti SC），「周一 ◆ 周日」之间的连接线是虚线钢轨，中间有菱形节点。
- 领票 → 检票：车票应有四角凹口、金色内细框、金属渐变标题、齿孔票根、底部雕版云带。
- 三种票面（午夜蓝 / 复古羊皮纸 / 余晖红棕）切一遍，确认深色票面是金色渐变标题、羊皮纸票面是墨色标题。
- 390px 手机视口：票面标题不应与右上角 G-07 邮戳重叠；底部状态章不应被票根遮住。
- 场景页：热点应是黄铜标点 + 印刷体票签，返回按钮是黄铜细边小牌，底部导航选中项是金色刻度线。
- 面板（行囊 / 手账 / 设置）：纸面应有纤维纹理与内细框。
- 键盘 Tab：按钮应有金色描边焦点环。

## 四、刻意未做的事

- **没有**设置 `.scene-art`、`.art-board`、热点（`.hotspot`）的任何 `transform` / `filter` / `perspective`。
  3D 与 2.5D 效果完全交给对方维护，本层不会与之抢占。
- **没有**改存档结构、`version`、`localStorage` 键名、剧情推进条件、事件数据、音频映射。
- **没有**替换或删除任何美术资源。
- **没有**改 `vintage-ticket.css` 等既有样式文件；本层是纯追加覆盖。

## 五、已知限制

1. **分享图不含新装饰。** `src/ui-refresh/ticketShare.ts` 用 Canvas 单独绘制导出 PNG，
   它不会自动继承 CSS 的凹口、齿孔与金渐变。屏幕上与导出的图片会有细节差异。
   若要求两者一致，需要另行改造 `ticketShare.ts`（本次未做，避免扩大合并面）。
2. **字体依赖系统。** Windows 用华文中宋，iOS 用 Songti SC，Android 多数机型回落到思源宋体或黑体。
   要完全统一字形需要内嵌字体子集，会显著增加微信首屏体积，本次未引入。
3. **凹口与齿孔依赖 CSS mask。** 微信内核（WKWebView / X5）均支持；极旧内核会退化为直角矩形，
   不影响任何功能与布局。
4. 开场标题使用 `journeyTitle`，当前名称为「鹅铁U彩」。

## 六、回滚

删除 `src/ui-refresh/sunday-refresh.css`，并删掉 `main.tsx` 里新增的那一行 import 即可，
项目立即回到合并前的样子。
