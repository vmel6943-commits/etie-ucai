# 字体授权

## 站酷小薇（ZCOOL XiaoWei）

- 用在哪里：标题、场景名、热点铭牌、按钮、导航、对白这类“招牌字”。见 `src/ui-refresh/typography.css`。
- 文件：`src/ui-refresh/fonts/zcool-xiaowei.woff2`（由官方 TTF 按本项目实际用到的 1076 个汉字子集化，约 259 KB）

## 正文

正文、表单与说明文字继续使用系统字体（PingFang SC / 微软雅黑 / Noto Sans CJK），不额外下载文件。

## 换字体时

1. 把新的 TTF/OTF 放到本目录。
2. 用 `python -m fontTools.subset 字体.ttf --text-file=<项目用字> --flavor=woff2 --output-file=xxx.woff2 --no-hinting --layout-features='*'` 子集化（只要项目实际用到的汉字，体积能小一个数量级）。
3. 改 `typography.css` 里的 `@font-face` 与 `--font-display`。
4. 如果是新的授权，替换本目录的 `OFL.txt` 并更新上面的说明。
