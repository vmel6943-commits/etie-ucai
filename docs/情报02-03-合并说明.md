## 八、判断流程（修复主线走不到第三幕的问题）

原版本的两次判断（`voteFirst` / `voteFinal`）是**死入口**：
`setPanel('voteFirst')` 全项目没有调用，`openCokeMaterial` 也不写 `evidence`，
导致 `canRevote()` 恒为假、`finalVote` 永远为空，而通往第三幕的 `startExploring()`
只在 `finalVote` 存在时才会被调用 —— 玩家会卡在情报工作台出不去。

现在改成：

```
读专报 → 追踪三层传播 → 【首次判断】→ 揭开真相 → 开皮箱 → 读四份材料
        → 【记录新的判断】→ 前后对比 → 乘务员对白 → 第三幕
```

- 首次判断内嵌在专报里，写 `firstVote`
- 再次判断从工作台托盘进入，写 `finalVote`，完成后直接 `startExploring()`
- 两次共用同一组 A/B/C 选项，用现有 `voteFeedback()` 输出「判断保持一致 / 判断发生变化」

## 九、个人观点（工作台左下角 · 两页连续投票）

原来的左下角热点（配置里 id 是 `witness`，位置 `x:18, y:74`）叫「原始报道」，
在旧版会弹出图书馆事件的「两份现场证词」。现在整体换成**同一个弹窗内的两页连续投票**：

```

  → 第 1 页 01/02 可口可乐AI广告（4 选 1）→ 提交投票
  → 第 2 页 02/02 红果短剧（4 选 1）→ 提交投票并完成任务
  → 完成页（两题记录 + 返回情报工作台）
```

- 热点名称与位置不变：`个人观点`（`CokeMaterials.tsx` 的 `cokeHotspots.witness`）
- 弹窗标题仍是 `个人观点`
- 顶部有进度指示：第 1 页 `● ─ ○ 01/02`，第 2 页 `● ─ ● 02/02`
- 页间是淡入位移动画，不关闭弹窗、不跳转页面
- 未选任何选项时提交按钮不可点

### 状态与计票

| 情况 | 行为 |
| --- | --- |
| 一题都没答 | 从第 1 页开始 |
| 只答了第 1 题 | 关闭弹窗或刷新后再次进入，**直接从第 2 页继续** |
| 两题都答完 | 进入即为完成页，显示两道题的选择结果 |
| 保存失败 | **不清空选择、不跳页**，提示重试 |

- 每题一个存档键：`choices['opinion-coke-ai']`、`choices['opinion-hongguo-short']`
- 两题都写入后才设置 `opinion-done` flag，工作台左下角热点随即显示「已完成」勾选
  （`App.tsx` 的 `recorded()` 里加了一个判断，见下）
- **没有虚构数据**：页面不显示任何票数或百分比

### 关于统计方式的限制（必须让使用者知道）

现在用 localStorage 保存，只能识别**这台设备的这个浏览器**：
换一台设备、换一个浏览器，同一个人会被当成新用户；
也无法汇总「全体乘客」的实时票数。

要真正统计，需要后端 + 用户唯一 ID。为此已经留好接口：
`src/data/opinion.ts` 的 `readOpinionTally()` 目前固定返回 `null`，
接上服务后只改这一个函数即可，组件不用动：

```ts
export function readOpinionTally(): OpinionTally | null {
  // 接后端后：return await fetch('/api/opinion/summary').then(r => r.json());
  return null;
}
```

### 视频文件的位置

放在 Vite 的 public 目录，构建后原样出现在站点根目录：


### 播放器

- HTML5 `<video controls playsInline preload="metadata">`，16:9，不进全屏也能播放
- 默认不自动播放（实测 `paused: true`）
- 切换卡片时旧元素卸载并 `pause()`，不会两支同时响
- 关闭弹窗时 `useEffect` 清理函数暂停，声音立即停止
- 文件缺失/解码失败：显示「这段视频暂时播放不了」并写出缺失路径，不出现无说明黑屏
- 手机端：`playsInline` 防止 iOS 强制全屏；卡片两列；无横向溢出
